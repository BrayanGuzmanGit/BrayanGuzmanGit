## 🚀 Proyectos destacados

### Sistema web orientado a servicios para la gestión de inspecciones fitosanitarias

Aplicación web desarrollada con Node.js, Express.js, React y PostgreSQL/Supabase.

El proyecto está compuesto por dos servicios backend independientes que se comunican mediante APIs REST. Incluye autenticación, autorización basada en roles, operaciones CRUD y procesos relacionados con la gestión de solicitudes e inspecciones.

**Tecnologías:** Node.js · Express.js · React · PostgreSQL · Supabase · REST APIs

**Repositorios:** [Entities Service](https://github.com/BrayanGuzmanGit/entities-service5to) · [Inspections Service](https://github.com/BrayanGuzmanGit/inspections-service) · [Frontend](https://github.com/BrayanGuzmanGit/IcaInspecciones)
